[inndex.html](https://3qnrpdwd.github.io/login_logger/templates)- index page

This program encrypts and stores login information in Python and shows it beautifully on the web ui. When you press the 'show' button, it decrypts and shows in real time, and there is no security threat because it only works on the local network. You can also export or import account information and use json data.
